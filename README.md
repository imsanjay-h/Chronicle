Chronicle — Personal Portfolio Website

A personal portfolio website built to bring creativity, digital media, and personal expression together in one place.

Chronicle is a responsive, multi-page website designed with a cinematic aesthetic, combining minimalist layouts, warm accents, and a dark visual theme. The project focuses on creating a distinctive digital space that feels personal while remaining simple to navigate across desktop and mobile devices.

Overview

The website is built using standard web technologies and organised into separate pages for different sections of the portfolio. Its structure is designed to be easy to maintain, customise, and expand over time.

Features

- Responsive layout for mobile and desktop screens
- Multi-page navigation
- Dark, cinematic visual design
- Reusable styling through a central CSS stylesheet
- Lightweight JavaScript for interactive elements
- Separate pages for different areas of the portfolio
- Static hosting through GitHub Pages

Built With

- HTML5 — Page structure and content
- CSS3 — Layout, styling, responsiveness, and visual effects
- JavaScript — Interactive functionality
- GitHub Pages — Website hosting and deployment

Development

Chronicle is a static website, so it does not require a backend server or database. The source files can be edited directly, and updates can be published through the GitHub repository.

To work on the project locally:

1. Clone or download this repository.
2. Open "index.html" in a browser or use a local development server.
3. Edit the HTML, CSS, and JavaScript files as needed.
4. Commit and push changes to publish updates through GitHub Pages.

Future Development

The project is intended to evolve over time, with room for additional sections, improved interactions, richer visual details, and further refinements to the overall experience.
